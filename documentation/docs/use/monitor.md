# About monitoring in PGF WatchTower

PGF WatchTower continuously collects, stores, visualizes, and analyzes various metrics from PostgreSQL. With PGF WatchTower, you can monitor your database environment and gain insights into its behavior. 

Some of the key functionalities of monitoring in PGF WatchTower are:

- **Performance monitoring**: PGF WatchTower collects metrics such as operations latency, throughput, latency, and resource utilization (CPU, memory, disk I/O). This helps identify performance bottlenecks and optimize query execution for better efficiency.
- **Resource utilization:** PGF WatchTower monitors CPU usage, memory, disk I/O, and network traffic to optimize resource allocation.
- **Database health checks**:  PGF WatchTower monitors various metrics, such as replication status, uptime, connections, server status, and error rates, to ensure system availability and identify potential issues.
