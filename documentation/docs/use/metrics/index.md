# About PFMM metrics

Postgres1st (PFMM) collects a range of metrics across database systems to provide comprehensive monitoring and analysis capabilities. 

PFMM supports monitoring for PostgreSQL databases. It gathers metrics related to database performance, resource utilization, health, and other important aspects. 

These metrics power the [PFMM dashboards](../../use/dashboards-panels/index.md) to help you monitor, troubleshoot, and optimize your database environments.

## Filtering metrics by label

You can query metrics directly in PFMM using **Explore > Metrics** in the sidebar. This opens the **Grafana Metrics Explorer** where you can select a metric and filter results using **Label filters**. Labels let you narrow results to a specific service, node, environment, cluster, or any other label attached to your monitored services. For a complete list of available labels, see [Labels reference](../../reference/labels-reference.md).
