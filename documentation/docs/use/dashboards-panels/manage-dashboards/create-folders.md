
# Create dashboard folders

Folders help you organize and group PGF WatchTower dashboards, which is crucial when you have multiple dashboards or teams using the same PGF WatchTower instance.

!!! note alert alert-primary "Note"
    To create a dashboard folder, you must have PGF WatchTower's **Admin** privileges.

To create a dashboard folder:
{.power-number}

1. On the PGF WatchTower dashboards page, from the side menu, go to <i class="uil uil-apps"></i> **Dashboards >  New > New folder**.

2. Enter a unique name for your folder and click **Create**.
