# PostgreSQL End Of Life
## Description
This check notifies that your version of PostgreSQL has reached End-of-life.
End-of-life releases no longer receive fixes, including security fixes.

## Resolution
Upgrade to the latest version of PostgreSQL, following the [upgrade instructions](https://docs.percona.com/postgresql/15/major-upgrade.html).

For more information, check out the [support lifecycle information](https://www.postgresfirst.com/support)
